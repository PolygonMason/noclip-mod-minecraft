## 📖 About

NoClip Mod enables fly-through-walls movement in single-player for building, exploration, and debugging redstone contraptions without creative flight restrictions.

---

## ✨ Features
<a name="features"></a>

- **Wall Clip** — pass through any block freely.
- **Speed Control** — configurable no-clip movement speed.
- **No Fall Damage** — optional fall damage disable while active.
- **Toggle Key** — instant enable/disable.
- **HUD Indicator** — shows when no-clip is active.
- **Singleplayer Only** — auto-disabled on server connection.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
